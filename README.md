# Huerta Urbana

Sitio web de dos páginas con una guía básica para armar una huerta en poco espacio. Es el trabajo práctico de HTML, CSS y Git/GitHub.

## Estructura

```
proyecto-web/
├── index.html      # Página de inicio
├── nosotros.html   # Página del equipo (enlazada con index.html)
├── css/
│   └── style.css   # Estilos compartidos
└── README.md
```

## Cómo ejecutarlo

1. Clonar el repositorio:
   ```
   git clone https://github.com/rominiamacuri02-art/proyecto-web.git
   cd proyecto-web
   ```
2. Abrir `index.html` con doble clic en el navegador. No necesita instalar nada.
3. Usar el menú superior para navegar entre Inicio y Nosotros.
